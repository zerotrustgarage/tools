Multifactor authentication

The Duo Authentication Proxy (version 6.5.1 or later) in Duo-only RADIUS mode. The domain controller checks the password; only the user name and the chosen factor go to the proxy.

The shared secret is protected with DPAPI on this computer. It is the only secret the console stores.

CMMC IA.L2-3.5.3 expects multifactor authentication for network access to every account. Without it, each sign-in is recorded as an open IA.L2-3.5.3 item for the POA&M.
